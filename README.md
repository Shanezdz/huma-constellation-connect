# HUMA — The Solidarity Constellation

**Mapping the invisible architecture of human solidarity.**

HUMA is a poetic digital constellation designed to make visible the quiet networks of knowledge, time, care, mutual aid and human connection that already exist across borders.

HUMA is not a social network, a charity platform or a donation app. It is an evolving digital experience at the intersection of poetic interaction, data humanism, social design and civic imagination.

## The idea

Humanity already contains an immense invisible infrastructure of solidarity. HUMA explores ways to perceive it, narrate it and, eventually, activate it without reducing human relationships to profiles, rankings, likes or transactions.

The experience unfolds through six narrative acts:

1. **SEE** — perceive the constellation
2. **GIVE / ASK** — leave a human gesture
3. **ECHO** — observe how one gesture may propagate
4. **REMEMBER** — encounter stories of transmission and care
5. **FEEL** — sense a speculative collective pulse
6. **IMAGINE** — explore possible futures of cooperation

## Principles

- Poetic interface on the surface, civic intelligence underneath
- Human dignity before engagement metrics
- No social-media mechanics
- Transparency about prototype, illustrative and speculative data
- Anonymity where it protects dignity
- Reciprocity rather than extraction
- A calm, contemplative and internationally legible visual language

## Visual language

HUMA uses a deep spatial environment, restrained luminous particles, fine connection lines, warm ivory, soft gold, celestial blue and muted aurora green. Motion is slow and organic. The interface deliberately avoids conventional dashboards, NGO clichés, aggressive cyberpunk aesthetics and feed-based interaction.

## Status

HUMA is currently an evolving prototype. Illustrative stories, constellation points and speculative metrics are explicitly identified as such and should not be interpreted as verified real-time global data.

## Development

The project is built with TypeScript, React, TanStack Router, Tailwind CSS and Vite.

```sh
git clone https://github.com/Shanezdz/huma-constellation-connect.git
cd huma-constellation-connect
npm install
npm run dev
```

## Project direction

HUMA is being developed as an independent open digital project. Its long-term exploration concerns the representation of invisible solidarity, knowledge transmission, reciprocal capacity and new forms of civic imagination at planetary scale.
